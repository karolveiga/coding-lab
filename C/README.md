Exercícios de C — Faculdade

Repositório destinado aos exercícios e atividades desenvolvidos durante as aulas de C na faculdade.

Aqui estão reunidos códigos feitos ao longo da disciplina, com o objetivo de praticar os fundamentos da linguagem e desenvolver minha lógica de programação.

📚 Conteúdos praticados

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores e expressões
- Estruturas condicionais ("if", "else", "switch")
- Estruturas de repetição ("for", "while", "do while")
- Vetores
- Matrizes
- Funções
- Ponteiros
- Strings
- "struct"
- Algoritmos e lógica de programação

🗂️ Organização

Os exercícios estão organizados de acordo com os conteúdos e/ou aulas da disciplina.

.
├── exercicios/
│   ├── ...
│   └── ...
└── README.md

A estrutura pode ser atualizada conforme novos exercícios forem adicionados.

🛠️ Tecnologias

- C
- Compilador GCC
- Git / GitHub

🎓 Objetivo

Este repositório funciona como um registro da minha evolução na programação em C, reunindo exercícios realizados durante a graduação e servindo como material de consulta e prática.
